# SRT 字幕整理工具

整理 AI 語音辨識產出的 SRT 字幕（繁體中文為主，可混英文）：

| 功能 | 參數 | 預設 |
|---|---|---|
| 斷句修正：字幕交界切在詞中間時接回並重新斷句 | （預設開啟）`--no-resegment` 關閉 | 開 |
| 取代表：修正常見錯字、同音字、拼錯的英文術語 | `--replace 檔案` | 關 |
| 長字幕切分：超過長度的字幕在詞界切成兩條 | `--split-chars 20` | 關 |
| 時間軸檢查：列出過快、過短、重疊的字幕 | （一律檢查） | 開 |
| 時間軸修正：自動修正上述問題 | `--fix-timing` | 關 |
| 建議詞：找出詞典沒有的人名、術語 | `--suggest-terms 檔案` | 關 |
| 同音詞檢查：找出同一個詞被辨識成不同同音字 | `--homophones 檔案` | 關 |
| 內建台灣用詞詞典（臺大、衛福部、健保…） | `tw_dict.txt`，`--no-builtin-dict` 停用 | 開 |

原本的換行、對話行（`- ` 開頭）與格式標籤（`<i>`、`{\an8}`）都會保留；沒被修改的字幕原樣輸出。

```
原：「我們明天要去台」|「北看展覽」
新：「我們明天要去台北」|「看展覽」
```

## 安裝

```bash
pip install -r requirements.txt
```

（選用）下載 jieba 大詞典，台灣用詞較完整。放在 `srt_resegment.py` 旁邊就會自動使用：

```bash
curl -L -o dict.txt.big https://raw.githubusercontent.com/fxsjy/jieba/master/extra_dict/dict.txt.big
```

## 圖形介面（GUI）

```bash
python srt_gui.py
```

或直接雙擊：Windows 用 `run_gui.bat`（也可以把 SRT 檔拖到圖示上），macOS 用 `run_gui.command`。

1. **字幕檔**：選擇輸入 SRT，輸出檔預設為同資料夾的 `*.fixed.srt`。
2. **詞典與取代表**：加入自訂詞典、取代表；「開啟編輯」用系統預設編輯器打開。
   - 「找建議詞」產生 `*.terms.txt`，刪掉不是詞的行後加入詞典。
   - 「找同音詞」產生 `*.homophones.txt`，把要統一的行刪掉「# 」後加入取代表。
3. **處理選項**：斷句修正、合併、切分長字幕、修正時間軸，以及長度與門檻。
4. 先按 **預覽修改** 看會改哪些地方（紅色為原文、綠色為修改後），沒問題再按 **執行並輸出**。

設定（詞典、取代表、選項）會記在 `~/.srt_clean_up_gui.json`，下次開啟自動帶入。
GUI 使用 Python 內建的 tkinter；Linux 若沒有，請安裝 `python3-tk`。

## 建議流程

```bash
# 1. 找出詞典沒有的詞、同音的不同寫法
python srt_resegment.py input.srt --dry-run --suggest-terms terms.txt \
    --homophones homophones.txt --homophones-fuzzy

# 2. 編輯 terms.txt（刪掉不是詞的行）
#    編輯 homophones.txt（要統一的行刪掉「# 」、箭頭右邊改成正確寫法）

# 3. 正式處理，同時輸出修改清單
python srt_resegment.py input.srt --dict terms.txt --replace homophones.txt \
    --split-chars 20 --fix-timing --report changes.txt
```

輸出預設為 `input.fixed.srt`，可用 `-o` 指定。

## 各功能說明

### 斷句修正

檢查每一對相鄰字幕：把兩段文字接起來，用分詞的詞頻機率計算「在原斷點強制切開」比「最自然的分詞」
差多少，差很多代表切到詞中間（「台|北」「設|定」）。之後在原斷點前後 `--max-shift` 個字內找新斷點，
考量：不切斷詞、離原斷點近、斷在標點或空白後、下一句不以語助詞（了、嗎、呢、啊、們）開頭、
上一句不以「的、在、把」結尾、長度不超過 `--max-chars`。時間依字數比例重新估算。

不會處理的情況：
- 下一句只是正常接續（「今天天氣很好」|「人很多」）
- 重複字（「對」|「對」、「講」|「講」）
- 兩條字幕間隔超過 `--max-gap` 秒
- 對話行、句子中間有格式標籤的字幕

### 取代表 `--replace`

```
# 每行「錯誤 => 正確」，也可用 Tab 分隔，# 開頭為註解
mosaism => mosaicism
亞斯蒂 => 亞斯提
# 正規表示式以 re: 開頭；(?i) 不分大小寫；\1 引用群組
re:(?i)(?<![A-Za-z])pgt-?a(?![A-Za-z]) => PGT-A
```

- 純英數的詞只比對完整單字（`AI` 不會換到 `AIR`）。
- 正規式裡中文旁邊不要用 `\b`（Python 會把中文字當成單字的一部分），請用 `(?<![A-Za-z])`。
- 取代後的正確詞會自動加入分詞詞典。
- 取代在斷句修正之前做一次；斷句修正後會再檢查字幕交界，被切成兩半的錯字
  （「移」|「運生殖中心」）也會被取代，取代後的詞放到原本佔比較多的那一邊。
- 每個出現的地方都會被取代，不看上下文；錯字本身也是正常詞時要小心誤換。

範例：`examples/replace.txt`。

### 長字幕切分 `--split-chars N`

超過 N 字（中文 1、英數 0.5）的字幕切成兩條，必要時再切。優先切在空白或標點、詞與詞之間，
避免切開人名（詞典沒有的連續單字）、避免下一句以「的」開頭；兩段長度盡量平均，每段至少
4 字。時間依字數比例分配。

### 時間軸 `--fix-timing`

一律檢查並列在報告中：
- **過快**：每秒超過 `--max-cps`（預設 15）字
- **過短**：短於 `--min-dur`（預設 0.5）秒
- **重疊**：和下一條字幕時間重疊
- **時長≤0**

加上 `--fix-timing` 會：
- 重疊：把前一條的結束時間截到下一條開始。
- 過快、過短：把連續有問題的字幕當成一組，延伸到前後的空白時間，再依字數比例以 `--target-cps`
  （預設每秒 6 字）重新分配。例如 AI 把 16 條字幕擠在 1.3 秒內，會被攤開到前面的空白時段。
  這是推估值，建議對照影片確認。

### 同音詞檢查 `--homophones FILE`

以「建議詞」為起點，在整份字幕中找讀音相同的其他寫法，寫成取代表草稿（每行預設註解掉）：

```
# xu pei yang：許佩陽 8、許培陽 4、徐培陽 2、續培養 1
# 許培陽 => 許佩陽
# 徐培陽 => 許佩陽
# 續培養 => 許佩陽
```

確認後把要統一的行前面的 `# ` 刪掉（像「續培養」這種本來就是正確詞的就保留註解），
右邊預設是出現最多次的寫法，若不是正確寫法請改掉，再用 `--replace` 帶入。

- 預設只比對完全同音（不分聲調）。
- `--homophones-fuzzy` 加上近音：zh/z、ch/c、sh/s、n/l、-ng/-n、送氣/不送氣（t/d、p/b、k/g、q/j、c/z），
  可抓到「亞斯提 / 亞斯蒂」「張志婷 / 張子婷」，但雜訊也較多。
- 需要 `pip install pypinyin`。

### 詞典

- `tw_dict.txt`：內建台灣用詞（學校醫院簡稱如臺大、榮總，機構如衛福部、國健署，健保、軟體等），自動載入。
- `examples/dict_reproductive.txt`：生殖醫學詞典範例（試管嬰兒、囊胚、黃體素、拮抗劑…），用 `--dict` 載入。
- 詞頻越高越不容易被切開；「臺/台」、繁簡寫一種即可。

### 建議詞 `--suggest-terms FILE`

從整份字幕找出「常出現、內部結合緊密、前後搭配多樣、但詞典沒有」的詞，通常是人名、
機構、藥名、術語，寫成詞典格式：

```
亞斯提 2000   # 19 次 | 亞斯 | 提
許佩陽 2000   # 8 次 | 許 | 佩 | 陽
```

挑選後用 `--dict` 帶入，斷句判斷會準很多。最少出現次數用 `--suggest-min` 調整。

## 全部參數

| 參數 | 預設 | 說明 |
|---|---|---|
| `-o` | `<輸入>.fixed.srt` | 輸出檔 |
| `--report` | | 修改清單寫到檔案 |
| `--dry-run` | | 只顯示，不寫檔 |
| `--encoding` | 自動 | 輸入編碼（自動判斷 UTF-8 / UTF-16 / Big5） |
| `--dict` | | 自訂詞典（可多個） |
| `--main-dict` | 程式旁的 `dict.txt.big` | 主詞典；`none` 停用 |
| `--en-words` | | 英文單字表，修正切斷的英文單字 |
| `--replace` | | 取代表（可多個） |
| `--max-chars` | 18 | 斷句修正時每條的理想最大長度 |
| `--max-line` | 0 | 被修改的字幕超過此長度時折成兩行 |
| `--max-shift` | 8 | 新斷點離原斷點最多幾個字 |
| `--min-gain` | 3.0 | 修改門檻，越大越保守 |
| `--max-gap` | 1.5 | 間隔超過幾秒不處理 |
| `--no-merge` | | 不合併字幕 |
| `--no-resegment` | | 不做斷句修正 |
| `--split-chars` | 0 | 長字幕切分門檻（建議 20~24） |
| `--fix-timing` | | 修正時間軸 |
| `--max-cps` / `--min-dur` / `--target-cps` | 15 / 0.5 / 6 | 時間軸門檻 |
| `--suggest-terms` / `--suggest-min` | / 3 | 建議詞輸出檔、最少次數 |
| `--homophones` / `--homophones-fuzzy` | | 同音詞輸出檔、包含近音 |
| `--no-builtin-dict` | | 不載入 `tw_dict.txt` |

## 限制

- 分詞靠詞典，詞典沒有的專有名詞可能判斷錯，請用 `--suggest-terms` + `--dict` 補充。
- 不懂語意，也分不出說話者。
- 時間是依字數估算，不是重新對齊音訊。
- 被切開的數字（「20」|「24年」）不會自動接回，避免把兩個不同的數字接在一起。
